=== Descrição ===
Closes #22.

### Why
After a build, `data\shaders\ryujinx` holds two files per shader, `<key>.spv` + `<key>.res.json`: 57,374 files for 1.4.3, about 1.7 GB. Everything else the game reads is already one big file (`romfs.bin`, `bc7.pack`). Copying, backing up, scanning with antivirus or syncing the game folder (Dropbox, OneDrive…) is dominated by those small files.

### Change
- **`tools/pack_shaders.py`** (new) writes `data\shaders\ryujinx\shaders.pack`. The layout, little-endian:
  - `UTSHPK01`, u32 count, u32 0;
  - entries sorted by key: `{key[32] (binary SHA-256), u64 offset, u32 SPIR-V bytes, u32 reflection bytes}`;
  - then the data (each SPIR-V followed by its reflection).
  It writes to `.tmp`, then `os.replace`s it.
- **`tools/setup.py`**: after `run_ryujinx_xlate.py`, the shaders step packs when the pack is missing or older than a translated shader (`stale()`). A no-op rebuild doesn't rewrite 1.7 GB.
- **`src/gfx/vkb_shader.c`**: `load()` reads through `read_translation()`.
  - On first use, `pack_open()` reads the index (1.4 MB).
  - Lookups use a binary search on the key, and the two blobs come from positioned `ReadFile`s, which are safe from the prewarm threads with no lock.
  - With no pack, a bad header, or a key that isn't in the pack, it reads the loose files as before. So developer layouts, partial caches and `--new-only` additions keep working.
  - `used.txt` stays a loose file, since the game appends to it.

The loose files stay in the builder folder, because `--new-only` adds to them. A player copying the game somewhere else needs only `shaders.pack` + `used.txt`.

### Testing (Windows, RTX 4090 laptop, 1.4.3)
- Rebuild of an existing build folder: the step packed its 28,687 shaders into a 1,720 MiB pack.
- Played from a copy of the game folder holding only `shaders.pack` + `used.txt` in `data\shaders\ryujinx` (2 files instead of 57,375). The log shows `[vk] shader pack: 28687 shaders in data/shaders/ryujinx/shaders.pack`, no `no translation` messages, a save loaded, and the game ran and exited cleanly.
- `pack_shaders.py` round trip on a synthetic set (500 shaders + an orphan `.spv` without a reflection, which is skipped): every entry reads back byte-identical, with the index sorted. `stale()` is false right after packing, and true once a `.spv` is newer than the pack.

+"""Pack the translated shaders into one file: <dir>/shaders.pack, read by src/gfx/vkb_shader.c.
+
+usage: python tools/pack_shaders.py [<dir>]   (default data\\shaders\\ryujinx)
+
+The translation writes two files per shader, <key>.spv and <key>.res.json (~57,000 files for 1.4.3); the game reads
+the pack first and falls back to them. The loose files stay: the next translation run (--new-only) adds to them, and
+the pack is written again. Layout, little-endian: b'UTSHPK01', u32 count, u32 0, then count entries sorted by key
+{key[32] (the SHA-256), u64 offset, u32 SPIR-V bytes, u32 reflection bytes}, then the data (each SPIR-V followed by
+its reflection).
+"""
+import os
+import pathlib
+import re
+import struct
+import sys
+
+MAGIC = b'UTSHPK01'
+KEY = re.compile(r'[0-9a-f]{64}')
+
+
+def pack(folder, out=None):
+    folder = pathlib.Path(folder)
+    out = pathlib.Path(out) if out else folder / 'shaders.pack'
+    keys = sorted(p.stem for p in folder.glob('*.spv')
+                  if KEY.fullmatch(p.stem) and (folder / f'{p.stem}.res.json').is_file())
+    tmp = out.with_name(out.name + '.tmp')
+    offset = 16 + 48 * len(keys)
+    index = []
+    with open(tmp, 'wb') as f:
+        f.write(MAGIC + struct.pack('<II', len(keys), 0))
+        f.write(bytes(48 * len(keys)))   # the index, written once the offsets are known
+        for key in keys:
+            spv = (folder / f'{key}.spv').read_bytes()
+            refl = (folder / f'{key}.res.json').read_bytes()
+            f.write(spv)
+            f.write(refl)
+            index.append(bytes.fromhex(key) + struct.pack('<QII', offset, len(spv), len(refl)))
+            offset += len(spv) + len(refl)
+        f.seek(16)
+        f.write(b''.join(index))
+    os.replace(tmp, out)
+    return len(keys), offset
+
+
+def stale(folder, out=None):
+    """True if the pack is missing or older than a translated shader (the translation added or rewrote one)."""
+    folder = pathlib.Path(folder)
+    out = pathlib.Path(out) if out else folder / 'shaders.pack'
+    if not out.is_file():
+        return True
+    t = out.stat().st_mtime
+    return any(e.stat().st_mtime > t for e in os.scandir(folder) if e.name.endswith(('.spv', '.res.json')))
+
+
+def main():
+    folder = sys.argv[1] if len(sys.argv) > 1 else 'data/shaders/ryujinx'
+    n, size = pack(folder)
+    print(f'{n} shaders packed into {pathlib.Path(folder) / "shaders.pack"} ({size / 2**20:.0f} MiB)')
+
+
+if __name__ == '__main__':
+    main()
