    Sobre
    
        
    UltraTears é um port nativo não oficial de The Legend of Zelda: Tears of the Kingdom 1.4.3 para PC. Não é um emulador: o código do jogo é traduzido antes (recompilação estática ARM64 → C → x86-64) e o sistema do Switch e a API gráfica NVN são substituídos por implementações próprias em Windows e Vulkan.
    

        
    
          
    
          
    
            Criador e desenvolvedor principal
            kuraeow
            Todo o port — recompilação, runtime, camada gráfica Vulkan, áudio e o processo de build — é trabalho dele.
