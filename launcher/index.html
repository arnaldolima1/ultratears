      Sobre
      
        
      UltraTears é um port nativo não oficial de The Legend of Zelda: Tears of the Kingdom 1.4.3 para PC. Não é um emulador: o código do jogo é traduzido antes (recompilação estática ARM64 → C, compilado para o processador do PC) e o sistema do Switch e a API gráfica NVN são substituídos por implementações próprias sobre Vulkan, no Windows e no macOS.
      
        
      

        
      
          
      
          
      
            Criador e desenvolvedor principal
            kuraeow
            Todo o port — recompilação, runtime, camada gráfica Vulkan, áudio e o processo de build — é trabalho dele.
